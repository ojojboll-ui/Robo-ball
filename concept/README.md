# Konceptskisser

Originalskisser av RB och hans värld. Bilderna är nedskalade till 1600 px för att
hålla repot litet; originalen bör sparas separat (helst i Git LFS när spelrepot sätts upp).

| Bild | Visar | Relevans |
|---|---|---|
| `01-rb-och-fiender-farg.jpg` | RB möter en grupp fiender, färgsatt | stilreferens: tuschlinje, krita, neonrosa/blå mot dovt |
| `02-hopp.jpg` | RB mitt i ett hopp över terräng | ballistisk bana, kroppsspråk i luften |
| `03-laddar-hopp-pendelpil.jpg` | RB på huk med pendlande siktpil | siktläget — kärnan i styrningen |
| `04-ramp.jpg` | RB åker ner för en ramp | markkontrollern: fart i sluttningar, Sonic-arvet |
| `05-trapetser.jpg` | RB svingar i trapetser | förmåga 6 (kroken) och gungande stelkroppar |
